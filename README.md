# MAISON LOOK v4 — Fashion Atlas / GitHub Pages

고해상도 실사풍 WebP 화보를 사용하는 여성 패션 룩북·의류 백과. 순수 HTML/CSS/JavaScript이며 데이터베이스나 API 키가 필요 없습니다.

## v4 개선 내용
- 의류 아틀라스 `ui-*.webp` 이미지 30개를 전부 사진으로 교체. 그중 12개는 고해상도 3분할 스튜디오 화보 크롭이며 다른 항목은 기존 사진 에셋을 재사용합니다.
- **중요:** 모든 이미지가 해당 의류의 정확한 사진인 것은 아닙니다. 유사 참고 사진에는 상세 안내가 제공됩니다. 정확성이 중요한 항목은 사진뿐 아니라 의복 설명을 함께 확인해 주세요.
- 고품질 화보와 누락된 이미지 없이 GitHub Pages에서 작동하도록 소스를 묶고, 기존 룩북·아카데미·비교·일기 기능을 유지합니다.

## v3 개선 내용
- **v2에서 확대되어 흐릿했던 158–162px 썸네일 12장과 유사 프리뷰 이미지를 삭제**, 가능한 항목은 512×768px AI 실사풍 원본에서 재추출한 고품질 WebP로 대체. 긴 세로형 화보는 378×1024px 원본을 유지합니다.
- 실사풍 사진이 정확한 복식 예시를 제공하지 못하는 용어는 별도 **720×1080px 의상 형태 도해**로 대체하고 카드·모달에서 이를 표시합니다. 도해를 실제 사진으로 표시하지 않습니다.
- 의류 상세 가이드 58종, 룩북 20종, 기존 스타일링 비교·아카데미·즐겨찾기·브라우저 코디 일기·JSON 백업 보존.
- 스타킹·타이츠·레깅스·쇼츠·새틴 의류·원피스·소재 등 다수 용어와 영문 검색 추가.
- 레그웨어 비교 섹션과 데니어 학습 그래픽 추가.

## 배포
1. 이 디렉터리의 **내용물 전체**를 GitHub 저장소 `main` 브랜치 루트에 올립니다 (`index.html`이 루트).
2. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
3. 이미 사이트를 방문한 기기는 이전 PWA 캐시가 남을 수 있으므로 새로고침하세요 (`sw.js` 버전 갱신됨).

## 개발/검사
- `index.html`을 브라우저로 직접 열 수 있습니다. `python -m http.server 8000`으로 미리 보면 서비스워커와 상대경로를 더 정확하게 검증할 수 있습니다.
- 기능: 루트 해시 내비게이션, 필터·검색, 용어 상세·원본 WebP 새 탭 열기, 퀴즈, 즐겨찾기, 개인 데이터 로컬 저장·백업.
- 외부 링크나 서버로 코디 사진을 전송하지 않습니다. 개인 사진은 브라우저 데이터 저장 제한이 있으니 JSON 백업을 권장합니다.

## 이미지 사용 안내
- v4에서는 의류 아틀라스에 벡터 도해를 사용하지 않습니다. 다만 일부 사진은 해당 의류의 정확한 디자인이 아닌 비슷한 참고 화보일 수 있습니다. 구체적인 대응 관계는 `docs/IMAGE_CATALOG.md`에 기록했습니다.

- AI 생성 가상 모델 화보 및 이를 원본 크기에 맞춰 추출한 WebP를 사용했습니다. 모델은 실제 인물이 아닙니다.
- 의상 구조 도해는 사진이 아닙니다. 의상 사진과 형태 도해는 카드 유형에서 구분됩니다.
- 소스가 되는 2×2 스튜디오 이미지에서 **한 판당 4장씩** 추출했으며, 썸네일 이미지를 확대하지 않았습니다.
- 일부 이미지에는 동일한 모델과 의상을 보여주는 참고 사진이 재사용됩니다. 원본 이미지는 ZIP 용량 절감을 위해 포함하지 않았습니다. 결과 WebP는 포함됩니다.
- 분류·설명은 교육용으로 작성했으며 브랜드별 명칭 차이가 있을 수 있습니다.

자세한 검증: `docs/IMAGE_CATALOG.md`, `docs/SOURCES.md`, `CHANGELOG.md`.
