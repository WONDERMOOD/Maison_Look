# MAISON LOOK — 개인정보·로컬 데이터 안내

이 정적 사이트는 기본적으로 계정, 서버 API, 쿠키 분석 및 광고 추적을 사용하지 않습니다. 개인 데이터와 사진을 서버로 전송하는 기능이 없습니다.

- 좋아한 화보, 캡슐 체크리스트, 코디 다이어리는 접속한 브라우저의 **localStorage**에 저장합니다.
- 추가하는 사진은 브라우저에서 작은 WebP 데이터로 리사이즈한 뒤 저장됩니다. 원본은 업로드되지 않으며 서버에 저장되지 않습니다.
- 기록은 **브라우저·기기·웹사이트 출처별**로 분리됩니다. PC의 기록은 다른 스마트폰에 자동 동기화되지 않습니다.
- 캐시·사이트 데이터를 삭제하거나 시크릿 모드를 종료하면 저장 내용이 사라질 수 있습니다. `백업 저장` 버튼으로 JSON 파일을 별도로 보관하세요.
- 백업 JSON에는 사용자 코디 사진과 메모가 포함되므로 다른 사람에게 공유하지 않는 것이 좋습니다.
- 백업 복구는 기존 기록 전체를 교체하므로 기존 데이터를 먼저 백업하세요.
- 사진은 8MB 이하 JPEG/PNG/WebP만 받으며, 코디 기록은 최대 25개까지 저장합니다. 브라우저 저장 할당량에 따라 실제 한도가 더 낮을 수 있습니다.
- 서비스 워커는 정적 사이트 파일을 오프라인 열람용으로 캐시합니다. 카메라 권한, 위치, 계정 정보를 사용하지 않습니다.
